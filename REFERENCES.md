# References

This file lists the sources behind the facts in this course: React's documented behavior and APIs, the
React 19.3 and React Compiler releases, the Vite, Vitest, Testing Library and Oxlint tooling, the HTML, CSS,
DOM, JavaScript and accessibility standards each chapter relies on, and the Five Dice rules. Use it to check a
claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the Internet
Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or changes). Links into
source files on GitHub point at a fixed release tag or commit, and their archived copy is in
[Software Heritage](https://www.softwareheritage.org/), an archive of public source code.
Console output, warnings, test results and measurements shown in the chapters come from running the course's
own code with the versions listed in the [README](README.md), and aren't listed here. Neither are links to the
course's own project code or to its companion TypeScript course.
